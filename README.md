# f-lab

HTML, CSS, and vanilla JavaScript practice lab.

## Student Management

Open [`student-management.html`](student-management.html) in a browser.

- CRUD with `localStorage`
- Student ID format: `1BM24CB` + 3 digits
- Email must end with `@bmsce.ac.in`
- Course: BE / BCom / BTech / BSc (single select)
- CGPA grading with meme sound effects
- Search + column filters (course, year, grade)

Sound assets live in [`sounds/`](sounds/).
